# TrueClicks plugins for Codex and ChatGPT

Plugins for PPC account management by [TrueClicks](https://www.trueclicks.com). They work in Codex (CLI and the ChatGPT desktop app) and in ChatGPT Work running locally in the desktop app.

Looking for the Claude version? See [TrueClicks/claude-plugins](https://github.com/TrueClicks/claude-plugins).

## Available plugins

| Plugin | Description | Version |
|--------|-------------|---------|
| [google-ads](./plugins/google-ads) | Google Ads data download and account changes | 2.1.0 |

## Getting started

```text
codex plugin marketplace add TrueClicks/openai-plugins
```

Then install the plugin from `/plugins` in the Codex CLI or the **Plugins** tab in the ChatGPT desktop app. Setup steps are in the [google-ads README](./plugins/google-ads/README.md).

Visit [claudeppc.ai](https://claudeppc.ai) for documentation and FAQ.
